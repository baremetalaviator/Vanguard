# Vanguard

Physical airframe for Project Solaris — an autopilot built from scratch, documented on the Bare Metal Aviator YouTube series.

Holds: frame and wiring, mechanical design, the hardware bill of materials, and hardware bring-up notes.

Part of Project Solaris: [Nebula](https://github.com/baremetalaviator/Nebula) (firmware) · [Observa](https://github.com/baremetalaviator/Observa) (ground station) · [NovaLink](https://github.com/baremetalaviator/NovaLink) (protocol)
